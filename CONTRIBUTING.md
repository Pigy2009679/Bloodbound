# Contributing to BLOODBOUND

Thanks for your interest in the project.

## Before contributing

- Read [README.md](README.md), [DEVELOPMENT.md](DEVELOPMENT.md), and [BRAND_GUIDE.md](BRAND_GUIDE.md).
- Keep Nomad compatibility separate from PCVR assumptions.
- Do not describe a feature as working unless it has been tested on the target game version.
- Use original assets or assets with clear permission for redistribution.

## Suggested issue reports

Include:
- Nomad game version
- Quest device model
- Mod build or commit
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant logs or screenshots, with personal information removed

## Visual and performance standards

- Preserve the deep-crimson dark-fantasy identity.
- Prefer smooth, readable liquid motion over excessive particles.
- Consider VR comfort and Quest performance in every effect.
- Clean up spawned effects when casting stops or a target becomes invalid.

## Scope

This is an independent fan project and is not affiliated with Warpfrog or mod.io.
